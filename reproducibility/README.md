# Reproducibility Suite Overview

This directory contains everything required to independently reproduce every experimental finding, table, and figure reported in the manuscript.

### Contents
- `requirements.txt`: Python package dependencies.
- `environment.yml`: Conda virtual environment specification.
- `CONFIGURATION.md`: Hardware and execution environment specification.
- `RANDOM_SEEDS.md`: Explicit list of PRNG seeds used.
- `RUN_INSTRUCTIONS.md`: Step-by-step shell commands for replication.
- `DATA_PROVENANCE.md`: Data provenance, Zenodo links, and cryptographic checksums.
- `scripts/`: Production execution and summarization scripts.
